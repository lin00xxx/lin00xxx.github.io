1. Web Storage

Web Storage 是浏览器提供的本地存储能力，常用于保存用户偏好、临时数据、登录状态辅助信息等。

1.1 localStorage 与 sessionStorage

类型 生命周期 作用域 常见用途
localStorage 除非手动删除，否则长期存在 同源页面共享 主题色、语言偏好、长期缓存
sessionStorage 页面会话结束后清除 当前标签页 表单临时保存、单页流程数据

注意：Web Storage 只能保存字符串。如果要保存对象或数组，需要使用 JSON.stringify() 和 JSON.parse()。

3.2 闭包的作用

1. 保存私有变量

count 外部可以访问，但只能通过返回的函数修改。

2. 封装模块状态

意思是把要操作的数据和操作方法放在一起 避免暴露数据

3. 延长变量生命周期

message 在 1 秒后仍然可以被访问，这就是闭包的体现。

闭包延长生命周期的本质
  1. 垃圾回收机制：
    • JavaScript 引擎会定期回收不再使用的变量（垃圾回收）。
    • 如果一个变量还被其他函数引用，它就不会被回收。
  2. 闭包的作用：
    • 回调函数引用了外部的 message。
    • 所以 message 不会被回收，延长了生命周期。

  • 闭包会让被引用的变量继续保存在内存中。

5. this 指向

this 表示函数执行时的上下文。它的值不是在函数定义时决定的，而是在函数调用时决定的。

5.1 普通函数中的 this

1. 全局调用

在非严格模式下，浏览器中 this 指向 window。在严格模式下，this 是 undefined。

2. 对象方法调用

谁调用函数，普通函数中的 this 通常就指向谁。

3. 构造函数调用

使用 new 调用函数时，this 指向新创建的对象。

4. 事件处理函数

普通函数作为事件处理函数时，this 通常指向绑定事件的元素。

因为调用时是这样的：button.onclick=function(){ …. }

6. Promise

Promise 是 JavaScript 处理异步操作的重要方式。它解决了传统回调函数容易层层嵌套的问题。

promise是取餐号 是一个类 实际存在的存放未来会出现的东西的对象

6.1 Promise 的三种状态

状态 含义
pending 等待中
fulfilled 已成功
rejected 已失败

状态变化只能有两种：

  • pending -> fulfilled
  • pending -> rejected

一旦状态改变，就不会再变。

6.2 基本写法

resolve传给then reject传给catch

6.6 Promise.all()
